# mp3-player-android

MP3 player local-first estilo Spotify com Media3, fila de reprodução, mini player, tela Now Playing, upload via Storage Access Framework e recomendações offline.

## Como rodar (Android Studio)
1. Abra o projeto no Android Studio (Giraffe/Koala ou superior).
2. Aguarde o Gradle sync.
3. Conecte um dispositivo ou inicie um emulador (Android 13+ recomendado).
4. Execute o app pelo botão **Run**.
